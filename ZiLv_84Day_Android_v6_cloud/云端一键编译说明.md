# 自律 APP：GitHub 云端一键编译 APK

这个工程已经加入 GitHub Actions 自动编译配置：
`.github/workflows/build-apk.yml`

## 第一次使用

1. 登录 GitHub，新建一个仓库，例如：`zilv-app`。
2. 把这个压缩包解压后的全部文件上传到仓库根目录。
   必须能在仓库首页直接看到：`app`、`.github`、`build.gradle`、`settings.gradle`。
3. 打开仓库顶部 **Actions**。
4. 左侧选择 **一键编译自律APK**。
5. 点击右侧 **Run workflow** → 再点绿色 **Run workflow**。
6. 等待约 2～5 分钟，任务显示绿色 ✓。
7. 点开本次运行，在页面下方 **Artifacts** 找到 **自律-APK**。
8. 下载后解压，得到 `自律-v2.1.0.apk`，发到安卓手机即可安装。

## 以后更新源码

每次把新版源码上传/提交到 main 分支，系统会自动再次编译；也可以在 Actions 里手动点 **Run workflow**。

## 手机安装

如果安卓提示“禁止安装未知应用”，只需临时允许浏览器/文件管理器安装未知应用。APK 是 Debug 签名版本，适合你个人自用和测试。

## 隐私

APP 本身没有联网权限；GitHub Actions 只负责把上传到仓库的源码编译成 APK。若源码包含你的训练背景说明，建议把 GitHub 仓库设为 **Private（私有）**。
