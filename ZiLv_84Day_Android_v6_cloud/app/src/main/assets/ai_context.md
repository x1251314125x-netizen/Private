# 自律 APP — 给 ChatGPT 的续聊上下文

应用名称：自律
版本：84天语音指导版 v5

## 用户目标与背景
- 男，27周岁。
- 长期手淫，过去平均约每日1次。
- 当前主要困扰：兴奋/勃起状态下稍强刺激就出现很强射精欲望，主观感觉敏感、射精控制差。
- 最终目的：改善过快进入射精冲动的状态，提高兴奋和射精控制能力。

## 本版设计
1. 84天每天都有明确任务、顺序、预计时长。完整日计划在 `assets/training_plan.json`。
2. 今日每个任务都可点“开始”，进入动作讲解：为什么做、怎么做、常见错误、安全提示、计时。
3. 不局限PC肌：腹式呼吸、盆底放松、轻量盆底协调、兴奋度识别、Stop-Start、刺激节奏重塑、综合控制、每周复盘、恢复日。
4. 兴奋度0–10：主体尽量维持4–6；到6–7立即暂停；降到3–4再继续；避免反复冲9–10硬忍。
5. 盆底收缩只用约3–4成力，放松时间长于收缩；若练后更紧/更胀，暂停收缩1–3天，仅保留呼吸放松。
6. 不把禁欲或固定自慰次数当作治疗；不要求每次行为训练射精。
7. 记录：敏感度、控制感、盆底紧张度、首次到6–7级时间、6–7级后能否降回3–4级。
8. 所有记录仅存手机本地；APP无网络权限。
9. 停止条件：会阴/阴茎疼痛、麻木、明显排尿异常、血尿/血精、勃起明显恶化或症状突然明显变化时停止训练并建议就医。
10. 84天是自我管理观察周期，不承诺治愈，也不是医学上唯一或已验证的最佳固定处方。

## 下次对话
用户可能会直接上传“自律”APK或源码。优先读取本文件和 `assets/training_plan.json`，继续围绕改善敏感和射精控制优化APP，不要求用户重新讲背景。


## v5新增功能
- Android原生TextToSpeech中文语音提示。
- 原生震动提示，可在训练界面分别开关语音和震动。
- 腹式呼吸：自动循环“吸气4秒 / 呼气6秒”。
- 盆底放松：自动提示“吸气并放松会阴 / 呼气继续保持放松”。
- 盆底协调：读取当天detail中的收缩秒数、放松秒数和次数，自动提示“开始轻收缩 / 放松”。
- 兴奋度识别：约每45秒提醒评估兴奋度。
- Stop-Start/节奏重塑/综合控制：约每60秒提醒检查兴奋度与身体放松；点击6–7级暂停或3–4级继续时立即语音+震动。
- 训练结束时震动并语音提示完成。
