# 自律 — 84天敏感管理与射精控制训练（v5）

Android 8.0+，离线本地使用。

## v5 新增
- 原生中文语音训练提示（Android TextToSpeech）
- 原生震动提示
- 腹式呼吸自动“吸气/呼气”节奏
- 盆底协调自动“轻收缩/放松”提示，并读取当天秒数/次数
- Stop-Start 暂停/继续语音提示
- 定时提醒检查兴奋度、腹部/臀部/会阴放松
- 语音和震动可在训练界面单独开关

## 编译
Android Studio 打开本目录，等待 Gradle 同步后 Build APK。

应用名称：自律
包名：com.zilv.app
minSdk：26
targetSdk：35
版本：2.1.0


## ☁️ GitHub 云端一键编译 APK

本版本已加入 `.github/workflows/build-apk.yml`。把工程上传到 GitHub 后，在 **Actions → 一键编译自律APK → Run workflow** 即可生成可安装的 `自律-v2.1.0.apk`。详细步骤见 `云端一键编译说明.md`。
